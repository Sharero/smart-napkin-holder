# Умная салфетница

**Салфетки заканчиваются — администратор получает уведомление на телефон.**

Проект состоит из приложения для Android, программы для ESP32 и небольшого
сервера. ИК-датчик проверяет, есть ли бумага на выбранной высоте. Если стопка
опускается ниже этого уровня, приложение сообщает, что салфетницу пора пополнить.

## Как это работает

```text
ИК-датчик → ESP32 → Wi-Fi → Сервер → Android → Уведомление
```

1. Датчик замечает, что салфеток на контрольной высоте больше нет.
2. ESP32 ждёт 3 секунды: это помогает отсеять случайное срабатывание.
3. ESP32 отправляет состояние на сервер.
4. Сервер сохраняет его в базе данных.
5. Приложение получает новое состояние и показывает предупреждение.
6. После пополнения салфетница снова получает статус «Салфетки есть».

Датчик определяет **достижение порога**, а не точное число салфеток.

## Сборка приложения Android

Самый простой способ — через [Android Studio](https://developer.android.com/studio).

### Что установить

| Инструмент | Версия |
|---|---|
| JDK | 17 |
| Android SDK Platform | 35 |
| Gradle | 8.9 |
| Android Gradle Plugin | 8.7.3, уже указан в проекте |

Приложение рассчитано на **Android 8.0 и новее**.

### Порядок действий

1. В Android Studio выберите **Open** и откройте папку `android`.
2. В **SDK Manager** установите Android SDK Platform 35.
3. В настройках Gradle выберите JDK 17 и Gradle 8.9.
4. Дождитесь загрузки зависимостей и синхронизации проекта.
5. Подключите телефон с включённой отладкой по USB или создайте эмулятор.
6. Нажмите **Run ▶**.

Для сборки APK из той же папки:

```bash
gradle :app:assembleDebug
```

Результат:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## Запуск сервера

Этот раздел нужен для подключения ESP32 или проверки через симулятор.
Достаточно **Python 3.10 или новее**, дополнительные библиотеки не нужны.
Компьютер с сервером должен оставаться включённым.

Откройте терминал в корне проекта. Команды ниже предназначены для Bash:

```bash
export DEVICE_TOKEN="$(python3 -c 'import secrets; print(secrets.token_hex(24))')"
export ADMIN_TOKEN="$(python3 -c 'import secrets; print(secrets.token_hex(24))')"
HOST=0.0.0.0 python3 server/app.py
```

Создаются два разных ключа доступа:

| Ключ | Где используется |
|---|---|
| `DEVICE_TOKEN` | В прошивке ESP32 и симуляторе |
| `ADMIN_TOKEN` | В Android-приложении |

Сохраните значения в менеджере паролей. Чтобы увидеть их в своём терминале:

```bash
printenv DEVICE_TOKEN
printenv ADMIN_TOKEN
```

Сервер создаст файл `salfetki.sqlite3`. В нём сохраняются состояния и история.
По умолчанию используется порт `8080`.

## Подключение приложения к серверу

1. Откройте приложение и нажмите **«Настроить подключение к ESP32»**.
2. Введите адрес сервера и `ADMIN_TOKEN`.
3. Нажмите **«Сохранить и включить наблюдение»**.
4. Отправьте состояние через симулятор или включите ESP32.
5. Нажмите **«Обновить сейчас»**, чтобы сразу получить данные.

| Где запущено приложение | Адрес сервера |
|---|---|
| Эмулятор на компьютере с сервером | `http://10.0.2.2:8080` |
| Настоящий телефон | `http://IP-компьютера:8080` |

Например: `http://192.168.1.100:8080`. Телефон должен иметь доступ к компьютеру
по сети; для первого запуска подключите их к одному Wi-Fi.
Адрес `localhost` на телефоне указывает на сам телефон.

Когда приложение открыто, проверка выполняется каждые **10 секунд**.
В фоне используется WorkManager с интервалом **от 15 минут**; энергосбережение
Android может увеличить задержку. Мгновенные фоновые уведомления пока не реализованы.
